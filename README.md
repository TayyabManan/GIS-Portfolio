```

├── app/                    # Next.js App Router pages
│   ├── api/               # RESTful API endpoints
│   ├── blog/              # Blog with markdown content

│   └── layout.tsx         # Root layout component
├── components/
│   ├── layout/            # Header, Footer, Navigation

```
